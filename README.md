# COMEB UMES BREJÕES 2026

Site oficial do Conselho Municipal de Entidades de Base — COMEB 2026, da União Municipal dos e das Estudantes de Brejões (UMES BREJÕES).

## Grupos de Trabalho oficiais

- GT1 — Educação e qualidade do ensino
- GT2 — Assistência e permanência estudantil
- GT3 — Grêmios Estudantis e organização
- GT4 — Cultura, esporte e lazer
- GT5 — Universidade, formação e futuro

Cada GT possui 20 vagas, com disponibilidade controlada pela API do COMEB 2026.
